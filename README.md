# Jac Design Studio

Prompt Completo para Lovable: Jac Design (E-commerce Híbrido & Personalización)

Utiliza este prompt detallado y estructurado para generar la aplicación completa de Jac Design en Lovable, garantizando un diseño profesional, componentes interactivos avanzados y una experiencia de usuario optimizada para la conversión.

🚀 Prompt Principal para Lovable (Copia y Pega)

"Crea una aplicación web de comercio electrónico de página única (Single Page Application) moderna, elegante y totalmente funcional llamada Jac Design, especializada en fabricación digital (Impresión 3D), decoración de fiestas, letreros en icopor y madera, y repostería saludable.

El diseño debe tener una estética impecable (estilo Tailwind CSS con paleta Slate, Amber y Rose), tipografía limpia (Inter), diseño responsive perfecto para móviles y escritorio, y transiciones fluidas.

La aplicación debe incluir obligatoriamente los siguientes módulos interactivos:

Barra de Navegación Sticky con Insignias Dinámicas:

Logotipo con monograma 'JD' en degradado cálido y subtítulo de servicios (3D • Fiestas • Láser • Icopor • Postres).

Enlaces de anclaje fluidos: Inicio, Servicios y Colecciones, Personalizador en Vivo, Cotizador 3D IA, Galería de Clientes.

Contadores interactivos en tiempo real para el Carrito de Compras y la Lista de Deseos (Wishlist).

Hero Section Impactante:

Título principal enfocado en diseño integral para ideas y celebraciones.

Botones de llamada a la acción (CTA) para explorar catálogo o abrir el configurador.

Imagen destacada con efecto de tarjeta flotante y cristalería (backdrop blur).

Catálogo de Productos y Servicios con Filtros Interactivos:

Pestañas de filtrado dinámico por categorías: Todos, Fiestas & Eventos, Madera & Láser, Impresión 3D, Postres Saludables.

Tarjetas de producto con imágenes reales de alta calidad (usando Unsplash curado para decoración de eventos, letreros corporativos en madera, repostería fit, soportes 3D y tazas personalizadas).

Botones en cada tarjeta para: Añadir a Favoritos (con corazón interactivo), Añadir al Carrito con notificación flotante, y Botón de Vista Rápida (Quick View) que abre un modal con detalles e imagen ampliada.

Configurador Interactivo en Vivo (Live Preview Customizer):

Selector de producto base (Letrero Personalizado, Pocillo de Cerámica, Caja de Postres Fit).

Campo de texto editable en tiempo real para nombres, dedicatorias o logotipos.

Selector tipográfico (Moderna Sans, Elegante Serif, Técnica Mono).

Selector de color de tema/acabado con círculos interactivos (Ámbar Madera, Rosa Fiesta, Verde Healthy, Negro Grafito).

Mockup visual dinámico en tiempo real que refleja instantáneamente el texto, tipografía y color elegidos, junto con el precio actualizado.

Cotizador Instantáneo de Impresión 3D (Maker Studio):

Área de arrastrar y soltar (drag & drop) simulada para archivos STL, OBJ y STEP.

Selectores desplegables para material (PLA Ecológico, PETG Alta Resistencia, Resina UV Detalle Fino) y densidad de relleno (Infill 20%, 40%, 100%).

Botón de cálculo instantáneo que arroja notificaciones de presupuesto y volumen estimado.

Galería de Testimonios y Reseñas:

Cuadrícula con calificaciones de 5 estrellas y experiencias reales de clientes de eventos, oficinas y repostería.

Modales Interactivos Funcionales:

Modal de Vista Rápida: Muestra imagen grande, descripción completa y botón de compra directa.

Modal de Carrito de Compras: Lista de artículos añadidos con precios, opción de eliminar elementos individuales, cálculo de total en USD y botón funcional de "Proceder al Pago Seguro" que vacía el carrito con éxito.

Sistema de Notificaciones (Toasts): Alertas flotantes animadas (animate-bounce) en la esquina inferior derecha cada vez que el usuario añade un producto al carrito, modifica favoritos o calcula una cotización."

🎨 Especificaciones Técnicas y de Diseño para Lovable

Framework CSS: Tailwind CSS (incluido mediante CDN o configuración nativa de Tailwind en Lovable).

Iconografía: SVGs limpios en línea para carrito, favoritos, lupa, carga de archivos y botones de cierre.

Interactividad JS: Manipulación fluida del DOM mediante JavaScript vainilla moderno (estado de carrito, wishlist, filtros de catálogo, renderizado dinámico del configurador en vivo y modales).

Optimización visual: Uso de bordes redondeados modernos (rounded-2xl, rounded-3xl), sombras suaves (shadow-xl) y efectos de desenfoque (backdrop-blur-md) para una apariencia corporativa de alta gama.

Este prompt le dará a Lovable todas las instrucciones precisas para generar un producto final robusto, visualmente impactante y listo para comercializar tus productos de impresión 3D, madera y eventos.
